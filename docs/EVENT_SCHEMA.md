# BlackWatch Normalized Event — Schema Contract

**Status:** Draft v1 · **Schema version:** `1`
**Stability:** This is a frozen contract. Changes are **additive only**. Never rename or repurpose a field. Never change a field's type. To deprecate, mark deprecated and add a new field. Bump `schema_version` only on additive change; the core must read all versions it has ever emitted.

This document defines the single object that **every adapter produces** and the **entire core consumes**. Nothing in storage, search, rules, or routing is allowed to depend on a source-specific shape — only on this envelope.

---

## Design rules (read before adding any field)

1. **Source-independent.** A field must make sense for CloudTrail, Wazuh, a ClamAV scanner, GitHub audit, and syslog alike. If it only makes sense for one source, it goes in `raw` or `extra`, not the envelope.
2. **Transport is metadata.** `transport` is recorded for debugging only. No core logic may branch on it.
3. **Severity is assigned by rules, not sources.** Adapters leave `severity` null. Rules set it. (Aggregator modules like GuardDuty may pass through a `vendor_severity` into `extra`, but the authoritative `severity` is still rule-assigned.)
4. **Keep `raw`, always.** The original payload is preserved verbatim so events can be re-normalized later when an adapter improves. This is the insurance policy against early schema mistakes.
5. **Observables are flat and typed.** They power search today and correlation later. Put every correlatable value (IP, ARN, key id, bucket, hash) here in addition to wherever it lives structurally.

## The envelope

### Identity
| Field | Type | Req | Description |
|---|---|---|---|
| `event_id` | UUID (string) | yes | Unique per event. Generated by the core at ingest if the adapter doesn't supply one. |
| `schema_version` | int | yes | Envelope version. Currently `1`. |
| `dedup_fingerprint` | string | yes | Stable hash for collapsing repeats. Default = hash of (`action` + `actor.principal` + `target.id`). Adapters may override. |

### Time
| Field | Type | Req | Description |
|---|---|---|---|
| `event_time` | ISO-8601 UTC | yes | When the event actually happened (from the source). |
| `ingested_at` | ISO-8601 UTC | yes | When BlackWatch received it. Set by core. |

### Source
| Field | Type | Req | Description |
|---|---|---|---|
| `source.module` | string | yes | Dotted module id, e.g. `aws.iam`, `aws.cloudtrail`, `custom.clamav`, `wazuh`, `github.audit`, `syslog`. |
| `source.vendor` | string | no | Producing vendor/system, e.g. `aws`, `clamav`, `wazuh`, `github`. |
| `source.account` | string | no | Account/tenant context (AWS account id, org id, hostname). |
| `source.region` | string | no | Region/zone if applicable. |
| `source.transport` | enum | yes | How it arrived: `webhook` \| `lambda` \| `poll` \| `syslog` \| `queue` \| `api` \| `file`. **Metadata only.** |

### Classification
| Field | Type | Req | Description |
|---|---|---|---|
| `category` | enum | yes | Coarse bucket: `iam` \| `network` \| `storage` \| `auth` \| `compute` \| `finding` \| `audit` \| `other`. (`finding` = an already-detected result from a scanner/detector, e.g. ClamAV hit, GuardDuty finding.) |
| `action` | string | yes | Normalized verb, dotted + lowercase: `iam.policy.attach`, `auth.console.login`, `network.sg.authorize_ingress`, `storage.s3.policy.put`, `finding.malware.detected`. **This is the primary thing rules match on.** |
| `outcome` | enum | yes | `success` \| `failure` \| `unknown`. |

### Actor (who/what caused it)
| Field | Type | Req | Description |
|---|---|---|---|
| `actor.principal` | string | no | Identity that acted: ARN, username, service account, email. |
| `actor.type` | enum | no | `user` \| `role` \| `service` \| `root` \| `system` \| `unknown`. |
| `actor.is_root` | bool | no | True for AWS root usage. Convenience flag for rules. |
| `actor.via_role` | string | no | If acting through an assumed role / session. |
| `actor.source_ip` | string | no | Origin IP. |
| `actor.user_agent` | string | no | Origin user agent / client. |

### Target (what was affected)
| Field | Type | Req | Description |
|---|---|---|---|
| `target.id` | string | no | Primary affected resource id/ARN/path. |
| `target.type` | string | no | Resource type, e.g. `iam.user`, `s3.bucket`, `ec2.security_group`, `s3.object`. |
| `target.name` | string | no | Human-friendly name. |

### Observables (flat, for search + future correlation)
| Field | Type | Req | Description |
|---|---|---|---|
| `observables` | list of `{type, value}` | no | Every correlatable value. `type` ∈ `ip` \| `arn` \| `access_key` \| `bucket` \| `hash` \| `domain` \| `email` \| `hostname` \| `user`. Duplicates of structural fields are expected and fine. |

### Assessment (filled by rules, not adapters)
| Field | Type | Req | Description |
|---|---|---|---|
| `severity` | enum/null | no | `informational` \| `low` \| `medium` \| `high` \| `critical`. **Null until a rule sets it.** |
| `rule_matches` | list of string | no | Ids of detection rules that matched. Appended by the rule engine. |
| `tags` | list of string | no | Free-form labels from rules/adapters (`expected-automation`, `cross-account`, `prod`). |

### Payload
| Field | Type | Req | Description |
|---|---|---|---|
| `raw` | object/string | yes | Original payload, verbatim. Never parsed-away. |
| `extra` | object | no | Adapter-specific structured fields that don't fit the envelope (e.g. `vendor_severity`, scanner engine version). Searchable, but rules should prefer envelope fields. |

## Worked examples (how real sources map)

**1. Admin policy attached (CloudTrail → `aws.iam`)**
- `action`: `iam.policy.attach`
- `category`: `iam`, `outcome`: `success`
- `actor.principal`: `arn:aws:iam::123:user/dave`, `actor.source_ip`: `203.0.113.5`
- `target.id`: `arn:aws:iam::aws:policy/AdministratorAccess`, `target.type`: `iam.policy`
- `observables`: `[{arn, .../dave}, {arn, .../AdministratorAccess}, {ip, 203.0.113.5}]`
- `severity`: null (rule will set `high`)

**2. ClamAV hit on an S3 object (custom ECS scanner → `custom.clamav`)** — your DIY-vs-Macie case
- `source.module`: `custom.clamav`, `source.transport`: `webhook`, `source.vendor`: `clamav`
- `category`: `finding`, `action`: `finding.malware.detected`, `outcome`: `success`
- `target.id`: `s3://finance-uploads/q3/invoice.xlsx`, `target.type`: `s3.object`
- `observables`: `[{bucket, finance-uploads}, {hash, <sha256>}]`
- `extra`: `{ "signature": "Win.Trojan.Foo", "engine_version": "1.x" }`
- `severity`: null (rule sets `critical` for finance buckets)

**3. Failed console login (CloudTrail → `aws.cloudtrail`)**
- `action`: `auth.console.login`, `category`: `auth`, `outcome`: `failure`
- `actor.principal`: `arn:aws:iam::123:user/dave`, `actor.source_ip`: `198.51.100.9`
- `severity`: null (single failure = low; rule counts 5-in-10min → high in Phase 3)

---

## What is intentionally NOT here (yet)
- No correlation/session-graph fields — Phase 3 adds them additively.
- No enrichment block (geoip, threat-intel) — added under `extra` or a future `enrichment` object when needed.
- No per-event ACL/tenant fields — single-operator system for now.
